# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-12

### Added

- Initial release of Enver frontend dashboard
- Environment table with secure management
- Custom shimmer loading states
- View Details modal for environment information
- Activity logs display
- Member management integration
- Settings page with API tokens management
- Danger zone for account actions
- Responsive layout for dashboard and settings views
- Floating navigation bar
- Secure environment management UI
- API token creation with scope selection
- Team member management in projects

### Security Features

- Frontend integration with secure backend APIs
- Safe environment deletion with project cascade
- API token creation with scope selection UI
- Environment protection (owner-only deletion)
- Safe token creation and management in UI
- Environment details modal with member management
- Activity logs for project changes
